Overview

AI-Powered Dream Journal is a cross-platform mobile application designed to help users record, analyze, and better understand their dreams through AI-assisted interpretation and emotional pattern tracking.

The application combines mobile development, backend engineering, and AI-inspired analytical workflows to create a personalized reflective experience. Users can document dreams, answer contextual follow-up questions, identify recurring emotional and symbolic patterns, and receive personalized insights based on their experiences and interests.

The project was developed using Flutter for the frontend and Spring Boot with PostgreSQL for backend services and persistent data storage.

Motivation

Dreams often contain recurring emotions, symbols, and behavioral patterns that are difficult to track over time manually.

Most existing journaling applications only store text entries without helping users:

identify recurring themes,
detect emotional trends,
reflect on behavioral patterns,
or connect experiences over time.

This project aims to transform dream journaling into a more interactive and analytical experience by combining structured data collection with AI-inspired interpretation workflows.


Dream Recording System

Users can:
create and manage dream entries,describe dream details,attach emotions and context,and organize dreams chronologically.
Dreams are stored persistently using PostgreSQL.

The platform generates reflective interpretations based on:

dream descriptions,emotional context,recurring symbols,user beliefs,and behavioral patterns.

The interpretation system is designed to provide reflective insights rather than deterministic psychological conclusions.
